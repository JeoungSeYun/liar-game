# 라이어 게임 (웹)

친구들과 브라우저에서 즐기는 라이어 게임. 서버 하나 띄우고 방 코드만 공유하면 끝.

- 3~12명, 방 코드 4글자로 입장
- 카드 확인 → 순서대로 설명 → 토론(채팅) → 투표 → 라이어 최후의 기회 → 결과/점수
- 카테고리 10종, 바보 모드(라이어도 자기가 라이어인 줄 모름), 라이어 2명 모드
- 새로고침·연결 끊김 시 자동 재접속, 방장 자동 승계
- 휴대폰에서도 잘 됨

## 실행

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 접속.

## 친구 초대하기

### 1) 같은 와이파이라면
내 PC의 내부 IP로 접속하면 됩니다. (예: `http://192.168.0.12:3000`)

```bash
ipconfig
```
에서 IPv4 주소 확인.

### 2) 멀리 있는 친구라면 (터널)
서버를 켜둔 채로 새 터미널에서:

```bash
npm run tunnel
```

`https://xxxx.loca.lt` 같은 주소가 나옵니다. 그 주소를 친구에게 보내세요.
(처음 접속하면 localtunnel 안내 페이지가 뜰 수 있는데, 거기서 요구하는 IP는 터널 켠 사람의 공인 IP입니다. `curl ifconfig.me` 로 확인.)

ngrok이 있다면 `ngrok http 3000` 도 됩니다.

### 3) 항상 켜두고 싶다면 (무료 호스팅)
이 폴더를 GitHub에 올린 뒤 Render / Railway / Fly.io 에서 Node 서비스로 배포하면 됩니다.
Build: `npm install`, Start: `npm start`. 포트는 `PORT` 환경변수를 자동으로 읽습니다.

## 규칙 요약

1. 모두 같은 제시어를 받지만 라이어는 카테고리만 알고 제시어를 모릅니다.
2. 순서대로 제시어를 한 줄로 설명합니다. 라이어는 눈치껏 아는 척.
3. 토론 후 투표. 동률이면 한 번 재투표, 또 동률이면 라이어 승리.
4. 라이어가 지목되면 마지막 기회: 16개 단어 중 제시어를 고릅니다. 맞히면 라이어 역전승.
5. 점수: 시민 승리 +1 / 라이어 정답 +2 / 라이어 생존 +3

## 구조

```
server.js     방·라운드·투표 로직 (Node + ws)
words.js      카테고리별 제시어
public/       클라이언트 (HTML/CSS/JS, 프레임워크 없음)
```

제시어를 추가하려면 `words.js`만 고치면 됩니다.
