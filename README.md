# 라이어 게임

**[▶ 바로 플레이](https://jeoungseyun.github.io/liar-game/)** — 설치도, 로그인도, 서버도 필요 없습니다.

방을 만들고 초대 링크를 보내면 끝. 친구가 링크를 누르면 바로 들어옵니다.

- 3~12명, 방 코드 4글자
- 카드 확인 → 순서대로 설명 → 토론(채팅) → 투표 → 라이어 최후의 기회 → 결과/점수
- 라이어는 마지막에 제시어를 맞혀야 승리 (설정으로 끌 수 있음)
- 카테고리 10종 300단어, 바보 모드, 라이어 2명 모드, 단계별 시간 조절
- 새로고침·연결 끊김 자동 복구, 방장 자동 승계
- 휴대폰에서도 잘 됩니다

## 어떻게 서버 없이 되나요

방을 만든 사람의 **브라우저가 방을 맡습니다.** 나머지 사람은 WebRTC로 그 브라우저에 직접 붙습니다
(연결 중개는 PeerJS 공개 서버가 처음 한 번만 해줍니다). 중앙 서버에 게임 데이터가 남지 않습니다.

그래서 한 가지 규칙이 있습니다: **방장은 게임이 끝날 때까지 탭을 닫지 마세요.**
실수로 새로고침해도 같은 코드로 방이 되살아나고 친구들이 자동으로 다시 붙지만, 진행 중이던 라운드는 초기화됩니다.

방장이 나가도 방이 유지되길 원한다면 아래 서버 모드를 쓰세요.

## 규칙

1. 모두 같은 제시어를 받지만 라이어는 카테고리만 알고 제시어를 모릅니다.
2. 순서대로 제시어를 한 줄로 설명합니다. 라이어는 눈치껏 아는 척.
3. 토론 후 투표로 라이어를 지목합니다. 동률이면 한 번 재투표.
4. 마지막은 **라이어의 최후 추리**. 잡혔든 안 잡혔든 16개 단어 중에서 제시어를 골라야 합니다.

라이어는 **제시어를 맞혀야 이깁니다.** 투표 결과는 점수 폭을 정합니다.

| 투표 | 최후 추리 | 승자 | 점수 |
|---|---|---|---|
| 라이어 지목 성공 | 맞힘 | 라이어 역전승 | 라이어 +2 |
| 라이어 지목 성공 | 틀림 | 시민 승리 | 시민 각 +1 |
| 라이어 못 잡음 | 맞힘 | 라이어 완승 | 라이어 +3 |
| 라이어 못 잡음 | 틀림 | 시민 승리 | 시민 각 +1 |

라이어가 둘일 때는 맞힌 라이어가 +2, 나머지 라이어가 +1을 받습니다.

**라이어 최후 추리** 설정을 `지목됐을 때만`으로 바꾸면 예전 규칙이 됩니다. 라이어를 못 잡으면 그 자리에서 라이어가 이깁니다.

**바보 모드**를 켜면 라이어에게 **다른 제시어**를 줍니다. 본인도 자기가 라이어인 줄 모르는 채로 설명하게 됩니다.

## 서버 모드로 돌리기 (선택)

중앙 서버를 띄우면 방장이 나가도 방이 유지되고, WebRTC가 막힌 네트워크에서도 붙습니다.

```bash
npm install
npm start
```

`http://localhost:3000` 접속. 같은 와이파이면 내 PC의 내부 IP(`ipconfig`로 확인)로 친구가 들어올 수 있습니다.

멀리 있는 친구에게 열어주려면 서버를 켜둔 채 새 터미널에서:

```bash
npm run tunnel
```

나오는 `https://xxxx.loca.lt` 주소를 보내면 됩니다.

Render / Railway / Fly.io 에 올려도 됩니다. Build `npm install`, Start `npm start`, 포트는 `PORT` 환경변수를 읽습니다.

## 구조

```
public/index.html   화면
public/style.css    스타일
public/words.js     카테고리별 제시어
public/engine.js    게임 규칙 (브라우저·Node 공용, 전송 방식과 무관)
public/net.js       전송 계층 (P2P 또는 WebSocket)
public/app.js       UI
server.js           서버 모드용 정적 서버 + WebSocket
test/sim.js         4인 봇 통합 테스트
test/bots.js        수동 플레이용 봇
test/static.js      P2P 모드 로컬 확인용 정적 서버
```

`public/`만 GitHub Pages로 배포됩니다. 제시어를 늘리려면 `public/words.js`만 고치면 됩니다.

## 테스트

```bash
node test/sim.js
```

봇 4명이 두 라운드를 자동으로 플레이하며 역할 배정, 설명, 동률 재투표, 타임아웃, 재접속을 검사합니다.

P2P 모드를 로컬에서 보려면:

```bash
node test/static.js
```
